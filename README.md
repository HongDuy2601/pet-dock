# Pet Dock 🐾

Một bé thú cưng nhỏ chăm bạn giữa giờ làm: nhắc uống nước, vươn vai, thở chậm lại, và ngồi cạnh khi bạn mệt.

- Trang chính: https://hongduy2601.github.io/pet-dock/
- Dùng trên iPhone / iPad / Android (trình duyệt): https://hongduy2601.github.io/pet-dock/app/

Làm cho bạn bè dùng, không bán, không quảng cáo. Mọi thứ lưu trên máy của bạn.
